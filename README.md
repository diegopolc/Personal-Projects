README - Relational Database Certification Projects (freeCodeCamp)

This repository contains the projects completed as part of the Relational Database Certification from freeCodeCamp.org. Each project is designed to demonstrate practical skills in creating, managing, and manipulating relational databases using SQL and Bash.

Repository Contents

1. Build a Celestial Bodies Database

Description: Creation of a database containing information about celestial bodies using PostgreSQL.

Skills Demonstrated:

Database schema design.

Using PostgreSQL to create and manage tables.

Inserting and querying data.

Relevant Files:

celestial_bodies.sql: Contains the schema and executed queries.

2. Build a World Cup Database

Description: Creation of a Bash script to record information about World Cup matches in PostgreSQL and generate useful statistics through queries.

Skills Demonstrated:

Integration of Bash and PostgreSQL.

Automating data entry.

Writing queries to extract statistics.

Relevant Files:

world_cup.sh: Bash script.

world_cup.sql: World Cup database.

3. Build a Salon Appointment Scheduler

Description: Development of an interactive Bash program to manage customers and appointments for a salon.

Skills Demonstrated:

Creating interactive Bash programs.

Managing a PostgreSQL database for customer and appointment records.

Validating and handling user input.

Relevant Files:

salon_scheduler.sh: Bash script.

salon.sql: Salon database.

4. Build a Periodic Table Database

Description: Creation of a Bash script to query information about chemical elements from a periodic table database.

Skills Demonstrated:

Designing chemical databases.

Writing Bash scripts to perform queries.

Using complex operations in PostgreSQL.

Relevant Files:

periodic_table.sh: Bash script.

periodic_table.sql: Periodic table database.

5. Build a Number Guessing Game

Description: Development of an interactive terminal-based game using Bash that records user information and attempts in PostgreSQL.

Skills Demonstrated:

Creating terminal-based interactive programs.

Using PostgreSQL for data persistence.

Implementing game logic and user management.

Relevant Files:

number_guessing_game.sh: Bash script.

number_guessing_game.sql: Game database.

Technologies Used

SQL Language: PostgreSQL.

Tools:

Bash for automation and interactive program development.

PostgreSQL for database management.

Git for version control.

How to Use This Repository

Clone the repository to your local machine:

git clone https://github.com/diegopolc/Personal-Projects.git

Navigate to the desired project:

cd project-name

Import the corresponding SQL file into your PostgreSQL database:

psql -U your_user -d your_database -f file.sql

Run the Bash script following the project instructions.
